# tg-deliver

Чат для отправки и получения сообщений в Telegram через GREEN-API. React + TypeScript + Vite, без бэкенда.

## Запуск

```bash
cd client
npm install
npm run dev
```

## Как работает

1. Вводишь свои `idInstance` и `apiTokenInstance` от GREEN-API
2. Вводишь номер телефона — находится `chatId`
3. Пишешь и отправляешь сообщение
4. Ответ прилетает автоматически
